# PROJECT_MAP — древо семьи (I:\Семья\Древо)

Одностраничное приложение без сборки и зависимостей: открывается двойным щелчком
по `index.html`, работает офлайн, правки хранятся в браузере.

## Файлы

| файл | что внутри |
|---|---|
| `index.html` | разметка: шапка, холст, боковая панель, окна выбора и подтверждения |
| `styles.css` | всё оформление: палитра, карточки, панель, модальные окна, печать |
| `data.js` | **данные рода**: люди, браки, ветви, `candidates` (найденные, но недоказанные). Собран из пяти .docx, двух рассказов и проверки по архивам |
| `relations.js` | родство относительно выбранного человека: «мама», «дед», «прабабушка», сторона и глубина |
| `layout.js` | только геометрия: группы, поколения, две стороны от центральной пары, координаты карточек и линий |
| `app.js` | поведение: рендер, поиск, панель, редактор, связи, хранение, экспорт |
| `sync-config.js` | адрес общей базы (`url`) и ключ редактора (`key`). Пусто = синхронизация выключена |
| `sync.js` | обмен с Google-таблицей: `FamilySync.pull()` при открытии, `queue()` после каждой правки |
| `apps-script/Code.gs` | скрипт для Google-таблицы: отдаёт данные сайту и принимает правки |
| `apps-script/SETUP.md` | инструкция: таблица → скрипт → Web App → ключ в `sync-config.js` |
| `tools/check-lines.js` | проверка правил линий без браузера (зазоры, карточки, пересечения) |
| `preview.png` | как выглядит страница при открытии (для карты, не для работы) |
| `preview-zoom.png` | тот же вид при 200 % — проверка резкости шрифта |

Порядок подключения в `index.html`: `data.js` → `relations.js` → `layout.js` → `app.js`.

## Модель данных (`data.js`)

```js
window.FAMILY = {
  meta:     { title, subtitle, updated },
  branches: { ключ: { title, color } },        // цвет полосы на карточке
  people:   [{ id, first, middle, last, maiden, sex, branch,
               born, died, bornPlace, diedPlace, bio, note,
               facts: [[подпись, значение]], sources: [..], photo, isSelf }],
  unions:   [{ id, partners: [id, id], children: [id..], type, note }]
};
```

- `unions.partners` — 1 или 2 человека (один родитель — `type: 'single'`);
- `unions.children` — дети этой пары; связи «родитель» строятся только отсюда;
- `isSelf: true` — чья карточка помечается «вы» (влияет на подсветку линии);
- порядок `people` задаёт порядок ветвей слева направо;
- расхождения источников пишутся в `note`, а не «исправляются» молча.

## Что умеет страница

- дерево с зумом (колесо), перетаскиванием, кнопкой «показать всё»;
- масштаб сделан через CSS `zoom`, а не `transform: scale()` — текст остаётся
  резким на любом приближении (transform растягивает уже нарисованную картинку);
- поиск по имени и годам, переход к человеку;
- карточка: история, факты, примечание, источники, родня (кликабельно);
- **правка любого поля**, фото (уменьшается до 420 px), добавление и удаление людей;
- связи: добавить/убрать родителя, супруга, ребёнка; можно создать человека прямо из окна выбора;
- кнопка **«Родство»**: подписи на карточках считаются относительно выбранного человека (клик по карточке — пересчёт);
- линии: одна шина на семью, цвет по ветви ребёнка, двойная линия брака, точки-стыки;
- выбор человека подсвечивает всю цепочку вверх (родители, их родители и так далее): ствол и ножки к предкам, браки предков, обводка их карточек;
- удаление и импорт с кнопкой «Вернуть» (одна отмена);
- фильтр по ветви рода, свёртывание ветвей значком «−», счётчик «+N» у свёрнутых;
- выгрузка/загрузка `family-data.json`.

## Хранение

`localStorage`, ключ `family-tree-v2` (полный снимок людей и браков).
Файл `data.js` — исходные данные; если снимок есть, он важнее.
Чтобы вернуться к исходным: очистить данные сайта в браузере либо загрузить
выгруженный ранее JSON.

## Правило линий (layout.js)

Толщина линии `LINE_W = 1.5` px (stroke-width в `styles.css`). Отсюда
**просвет `CLEAR = 7 × 1.5 = 10,5` px** — минимум между любыми двумя линиями
и между линией и краем карточки.

- шины (горизонтали под семьёй) разводятся по своим высотам внутри поколения
  (`busYFor`), между соседними шинами всегда `CLEAR`;
- вертикали не входят в карточки: `xFree` держит `CLEAR + полутолщины` от края;
- длинные связи обходят чужие стволы коридором (`corridorFor`);
- на пересечениях горизонталь рвётся с зазором `CLEAR + полутолщины`,
  поэтому линии не пересекаются и не касаются;
- `CARD_GAP = 26` — чтобы ствол посередине пары не прилипал к карточкам.
