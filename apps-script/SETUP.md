# Общая база в Google-таблице — настройка с нуля

Пока не сделано, сайт работает как раньше: правки только в своём браузере.
Ниже — один раз на 10 минут, дальше всё работает само.

## 1. Создать таблицу

1. Открыть <https://sheets.new> (нужен вход в Google-аккаунт).
2. Назвать файл: **Древо семьи — база**.
3. Ничего не заполнять, листы создаст скрипт.

## 2. Вставить скрипт

1. В таблице: **Расширения → Apps Script**.
2. Стереть всё, что в редакторе, и вставить целиком файл
   [`apps-script/Code.gs`](Code.gs) из этого репозитория.
3. Сохранить (Ctrl+S).
4. Вверху выбрать функцию **setup** → **Выполнить**.
   Google спросит разрешения — **Разрешить** (это ваш же скрипт в вашей же таблице).
5. В журнале выполнения (внизу) появится строка **«Ключ редактора: xxxxxxxx»**.
   Этот ключ понадобится сайту — скопировать.

После этого в таблице появятся листы **Люди**, **Союзы**, **_meta**.

## 3. Опубликовать как Web App

1. **Развернуть → Новое развёртывание → тип «Веб-приложение»**.
2. Описание: `drevo api`.
3. **Запуск от имени: Я**.
4. **У кого есть доступ: Все** (иначе браузер родни не сможет прочитать данные).
5. **Развернуть** → скопировать ссылку вида
   `https://script.google.com/macros/s/AKfy…/exec`.

## 4. Подключить сайт

В файле `sync-config.js` заполнить:

```js
window.SYNC_CONFIG = {
  url: 'https://script.google.com/macros/s/AKfy…/exec',
  key: 'xxxxxxxx'
};
```

Закоммитить и запушить — GitHub Pages обновится за минуту.

## 5. Проверить

1. Открыть сайт, добавить любого человека.
2. Обновить страницу таблицы — в листе «Люди» должна появиться строка.
3. Открыть сайт на телефоне: человек должен быть виден.

## Что важно знать

- **Приоритет — таблица.** Если в таблице что-то правили, при открытии сайт
  покажет её версию и предложит «Вернуть» — вернётся то, что было в браузере.
- **Фотографии не синхронизируются**: у ячейки таблицы лимит 50 000 знаков,
  фото туда не влезает. Фото остаются в том браузере, где их добавили.
  Решение — отдельный шаг с Google Drive, если понадобится.
- **Ключ редактора** лежит в открытом коде сайта, то есть от злого умысла
  не защищает — только от случайной записи «не туда». Настоящая защита
  возможна только через вход по почте (Supabase и подобное).
- **Правки в таблице руками**: можно менять любые ячейки в «Люди» и «Союзы».
  Колонки «Факты (JSON)» и «Источники (JSON)» — это JSON вида
  `[["подпись","значение"],["подпись","значение"]]`; если правите их руками,
  следите за скобками, иначе строка будет пропущена.
- **Дети** в листе «Союзы» — id через запятую.
- Резервная копия: **Файл → Скачать → Microsoft Excel** раз в месяц,
  либо история версий таблицы (**Файл → История изменений**).
